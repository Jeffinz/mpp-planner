# Work Planner

ระบบจัดการตารางงานประจำเดือน ทำงานบนเว็บเบราว์เซอร์ เก็บข้อมูลใน Firebase Firestore และซิงค์แบบเรียลไทม์

## โครงสร้างโปรเจ็ค

```
work-planner/
├── index.html              หน้าหลัก โครงสร้าง UI และ modal
├── css/style.css           สไตล์ทั้งหมด
└── js/
    ├── firebase-config.js  ค่า config ของ Firebase
    └── app.js              ตรรกะหน้าปฏิทิน งาน และวันหยุด
```

## การใช้งาน

- เลือกเดือนและปีด้วยปุ่มลูกศรหรือ dropdown
- กด **เพิ่มงานใหม่** หรือกดช่อง "+ ว่าง" บนปฏิทิน เพื่อเพิ่มงาน
- ช่วงเวลามีสามแบบ: เช้า (08:30–12:00), บ่าย (13:00–16:30), ทั้งวัน (08:30–16:30) เมื่อเปลี่ยนช่วงเวลา ระบบจะเติมเวลาเริ่มและจบให้อัตโนมัติ ปรับแก้ได้
- กดที่งานเพื่อแก้ไขหรือลบ
- กดตัวเลขวันที่เพื่อตั้งหรือยกเลิกวันหยุดพิเศษ วันเสาร์และอาทิตย์เป็นวันหยุดอยู่แล้ว
- ปุ่ม **วันหยุด** เปิดรายการวันหยุดของเดือนที่แสดงอยู่
- ปุ่ม **จัดการข้อมูล** ลบงานทั้งหมด (วันหยุดจะไม่ถูกลบ)

## การตั้งค่า

1. แก้ `js/firebase-config.js` ให้เป็นค่าของโปรเจ็ค Firebase ของคุณ
2. ใน Firebase console เปิดใช้งาน Cloud Firestore และสร้าง collection ชื่อ `tasks` และ `holidays` (สร้างอัตโนมัติเมื่อบันทึกข้อมูลครั้งแรก)

## การรันในเครื่อง

โมดูล JavaScript ต้องรันผ่าน HTTP server เปิดไฟล์โดยตรง (`file://`) จะไม่ทำงาน

```bash
cd work-planner
python -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## ข้อควรทราบด้านความปลอดภัย

แอปนี้ไม่มีระบบเข้าสู่ระบบ ใครที่อ่านหรือเขียน Firestore ได้จะเห็นและแก้ไขข้อมูลทั้งหมดได้ ก่อนใช้งานจริงควรตั้งค่า Firestore Security Rules และเพิ่ม Firebase Authentication

## ความแตกต่างจาก index.html เดิม

- ไม่พึ่ง Tailwind CDN และ Lucide icons ลดการพึ่งพา CDN ภายนอก เหลือเพียง Firebase และ Google Fonts
- แสดงข้อความในงานด้วย `textContent` ป้องกันการแทรก HTML จากข้อความที่กรอก
- ลบข้อมูลทั้งหมดรอให้เสร็จก่อนแสดงผลสำเร็จ และแจ้งข้อผิดพลาดหากเกิดปัญหา
- เพิ่มการตรวจสอบว่าเวลาจบต้องหลังเวลาเริ่ม
- ปีในตัวเลือกมีช่วง 2025–2030 (เดิมมีเพียง 2569 และ 2570)
- ไม่มีฟีเจอร์แนบรูปภาพ แท็บความพร้อม และ mission type ที่มีอยู่ใน app.js เดิม
